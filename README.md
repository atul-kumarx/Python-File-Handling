## 📌 About This Project

Welcome to my Python File Handling repository!

This project is created to learn and practice Python File Handling concepts through simple, practical, and easy-to-understand programs.

Each operation has its own separate Python file with code examples and explanations.

**Goal:** Understand how Python works with files and directories.

## 🚀 How to Run

**Step 1:** Clone this repository.

```bash
git clone https://github.com/atul-kumarx/Python-File-Handling.git
```

**Step 2:** Open the project folder in VS Code.

**Step 3:** Run any Python file.

Example:

```bash
python 01_create_file.py
```
